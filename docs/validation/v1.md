## Lot et lecture

Le manifeste liste taille et SHA-256 de chaque fichier. Publication atomique depuis un répertoire temporaire ; refus de remplacer une version existante. Les contrôles vérifient liens, profils, séries compressées, JSON et schéma de tous les scénarios.
Le lot reste `prepared_pending_ui_review`. Une relecture par le responsable UI est nécessaire pour déclarer le gel N4 du plan ; aucun accord UI inventé.

Les résultats restent `validationStatus: not_validated` hors des cas de référence. Les sorties LOLA sont expérimentales. Les statistiques de taille, nombre de scénarios et temps réels sont dans `manifest.json` et `performance.json`.

Les temps du lot utilisent des caches d'éphémérides déjà préparés et certains profils déjà calculés lors des essais. Ce sont des mesures de cette exécution, pas un benchmark à froid ni une garantie de latence.
